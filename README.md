# TIME REVERSI

棋譜のパスは `ps` と表記します。旧表記 `pa` は読み込めません。

GitHub Pagesやitch.ioで公開したページを開くだけで、学習済みAIのMID・PROと対局できます。Pythonサーバーは不要です。CPUボタンは`PLY → EZY → MID → PRO → PLY`の順です。EZYはランダム、MIDは100回目、PROは307回目のモデルを使い、それぞれ64回の探索を行います。

公開用ZIPは`python scripts/package_web.py`で`dist/time-inversi-web.zip`に生成できます。itch.ioにはZIPをアップロードし、GitHub PagesにはZIPを展開した中身を配置します。詳しくは[公開・モデル更新の手順](docs/STATIC_HOSTING.md)を参照してください。

ローカル確認は`node scripts/preview.cjs`を実行して`http://127.0.0.1:4173/`を開きます。HTMLの直接起動ではWorkerが制限される場合があるため、MID・PROはHTTP/HTTPSで配信してください。
画像1に合わせた6×6盤で、黒から始まる同一端末の2人対戦、ランダムCPU、学習済みAIとの対戦です。マウスカーソルの代わりに手番のコマが追従します。合法マスの中心からマス幅の約80%以内に近づくと、最寄りの候補に着地点の影が現れ、クリックすると配置します。約100msで降下したあと一度小さく跳ね、計240msで接地してから挟んだコマが裏返ります。タッチでは明るいマスをタップして配置し、タップ後に駒のプレビューは残りません。キーボードではTab・矢印キーで移動し、Enter・Spaceで配置できます。ゲーム内の文字や画像の選択、タッチ操作による画面の拡大縮小とスクロールは無効です。動きを減らす設定にも対応します。

Time reversalは未使用の角への配置で発生します。手動のTIME REVERSALボタンはありません。初期時刻まで戻っても自動では反転しません。詳しいルールは [Time reversalのルール](docs/rules.md) を参照してください。

タイトルを押すと棋譜を連続座標形式（例: `d3c5f4e3f6`、パスは`ps`）で表示し、隣のCopyボタンで文字列をコピーできます。棋譜の上の入力欄に同じ形式の文字列を貼り付けてReplayを押すと、合法手を確認したうえで対局を最初から再現します。終局前の棋譜なら再生後にその局面から対局を続けられ、新しい駒を置くと再生ボタンは消えます。次の手番がCPUなら、盤面を一度クリックするまでCPUは待機します。Replayを押すと貼り付け欄は空になります。不正な棋譜では現在の対局を維持します。BGMボタンの左のNew gameボタンを押すとNew game?の確認が出ます。白CPUは初期EZY、黒は初期PLY（人が操作）です。CPUの手を待つ間は手番表示の下に「CPU thinking...」を表示します。CPUボタンは`PLY → EZY → MID → PRO → PLY`の順に切り替わります。パス時は中央にPASSの駒を800ms表示します。効果音はBGMボタンの状態に関わらず常に有効です。BGMボタンはBGMだけをオン・オフし、初期オンです。木漏れ日の小径と月影のゆりかごを交互に再生します。時間反転の回数に応じて、通常版→1.5倍速逆再生→1.5倍速順再生→2倍速逆再生→2倍速順再生へ切り替わります。終局後も再生を続け、New gameでは通常版の最初の曲へ戻り、棋譜を貼り付けてReplayすると、その棋譜の再生終了時点での時間反転回数に応じた版を最初の曲から流します。終局する棋譜では2倍速順再生版を流します。リプレイ中は切り替わりません。盤面のマスを選ぶ際はボタン音を鳴らしません。終局後はNew gameボタンの左に再生ボタンが現れ、再生中は一時停止ボタンに切り替わります。一時停止した場面から再開できます。UIはすべて英語で、逆行時は画面全体が青みを帯び、Time reversal時に一度脈動します。

盤面上の懐中時計は、順行・逆行マスの個数を32分割の扇形で示します。パスだけでは扇形を増やさず、駒が消えた場合はその分だけ更新します。白い針は両方の扇の境界を指し、順行で時計回り、逆行で反時計回りに進みます。

順行・逆行マスの濃淡は、それぞれの未消化履歴の末尾からパスも1手番として数えて決めます。次に消費する手番がパスなら最濃色の駒は表示されず、次の手番で駒が消えないことを見分けられます。

描画はPenrosanneの `docs/ui-design.md` と `src/ui/BoardView.js`、P3NROSEの `docs/GAME_SPECIFICATION.md` と `src/ui/board.js`・`src/ui/editor.js` を参考に、単色の上面・下向きの側面・硬い影・100msの接地を円形コマに適用しています。参考プロジェクトには依存しません。

横長画面では1080×1080の構図を基準に全体を拡大・縮小します。縦長のスマホ画面では盤面を画面幅近くまで広げ、時計と操作ボタンを上側、プレイヤー表示と対局ログを下側に大きく配置します。

ルールの検証: `node --test tests/*.test.cjs`

Python版ルールとAlphaZero方式の自己対戦学習は [学習環境の導入から実行までの手順](python_ai/README.md) を参照してください。Pythonが入ったPCで、この`Time Inversi`フォルダーだけから専用環境を作成できます。参考元の別フォルダーやNode.jsは学習には不要です。初回の依存ライブラリ導入にはインターネット接続が必要です。動作確認・本学習・停止／再開・評価の順にコマンドを掲載しています。

新方式PROをダウンロード後に学習する場合は、[PRO専用の実行手順](python_ai/PRO_TRAINING_GUIDE.md)を参照してください。

Git用フォルダーにはOracleの係数表・定跡データ、推奨事前学習重み、102回目からの追加学習に必要な保存点を含めています。Python環境は各PCで作成します。学習データの説明は[ORACLE_SOURCE.md](python_ai/pretrained/ORACLE_SOURCE.md)に記載しています。
